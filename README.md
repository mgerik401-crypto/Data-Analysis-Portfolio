# Data-Analysis-Portfolio
# 📊 Portafolio de Análisis de Datos en Excel
**Autor:** Erik Mercado Guzmán | Ingeniero Mecatrónico y Analista de Datos

Bienvenido a mi portafolio de Microsoft Excel. Este repositorio contiene proyectos prácticos enfocados en la limpieza de bases de datos, modelado relacional de información y análisis de rentabilidad, habilidades críticas para el control de programas y costos.

---

##  Estructura de Proyectos

### 1. Limpieza y Estructuración de Datos (Data Wrangling)
**Archivo:** `sf_boba_tea_shop_data.xlsx`
*   **Problema de negocio:** La base de datos original contenía coordenadas geográficas anidadas en una sola celda, impidiendo su uso en herramientas de mapeo y BI.
*   **Habilidades aplicadas:** Manipulación y extracción de cadenas de texto (Text-to-Columns, funciones SPLIT/anidadas).
*   **Resultado:** Normalización de coordenadas en columnas individuales (`lat` y `long`), dejando el dataset listo para análisis geoespacial.

### 2. Modelado Relacional y Consolidación Financiera
**Archivo:** `Cosmetics Inc. - Data for Pivot Table and VLOOKUP.xlsx`
*   **Problema de negocio:** Se requería consolidar un registro de 1,000 órdenes de compra cruzando códigos de productos desde catálogos externos para calcular los ingresos totales.
*   **Habilidades aplicadas:** Búsqueda y referencia avanzada (`BUSCARV` / `VLOOKUP`), lógica condicional y preparación de bases paramétricas para agrupación (Pivot Tables).
*   **Resultado:** Unificación de bases de datos relacionales y resumen ejecutivo de costos por producto y cliente.

### 3. Análisis Cuantitativo de Rentabilidad (ROI)
**Archivo:** `Movie-Data-Starter-Project.xlsx`
*   **Problema de negocio:** Evaluar la viabilidad financiera y el retorno de inversión de producciones cinematográficas analizando presupuestos vs. ingresos de taquilla, segmentado por género y director.
*   **Habilidades aplicadas:** Tablas dinámicas, fórmulas estadísticas, análisis de variaciones y estructuración de múltiples dimensiones.
*   **Resultado:** Generación de un modelo analítico base para la creación de un Dashboard financiero de apoyo a la toma de decisiones.
